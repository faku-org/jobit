¿Es este el código publicado?

Lo que corre en tu navegador, contra lo que cualquiera puede leer en el repositorio.

Lo que promete la política de privacidad sobre tu navegador lo cumple el JavaScript que te mandamos. Esta página dice qué commit es ese JavaScript y cómo comprobarlo sin tener que creernos.

Lo que se está sirviendo ahora

  • Commit: cargando…
  • Fecha del commit: …
  • Hash del build: …
  • Archivos: …

El detalle completo, con el sha256 de cada archivo, está en /version.json.

Esta comprobación sola no alcanza, y es a propósito que lo decimos. Esta página también la manda nuestro servidor: uno que quisiera mentir podría mentir acá. Lo que prueba es que el sitio sirve lo que declara. Que lo que declara sea el código público lo prueba lo de abajo, que corre en una máquina que no controlamos.

Comprobarlo sin confiar en nosotros

Con Bun y git, en tu máquina:

git clone https://github.com/faku-org/jobit
cd jobit
git checkout <el commit de arriba>
bun install --frozen-lockfile
bun run verificar

Baja /version.json, comprueba que cada archivo que sirve el sitio es el que dice, buildea ese commit en tu máquina y compara byte a byte. Si coincide, el código que corre en tu navegador es el que se puede leer en el repositorio. Si no, lo dice archivo por archivo.

Y si no querés instalar nada: una tarea pública del repositorio (Verificar el sitio) corre lo mismo todos los días en una máquina de GitHub, y el resultado de cada corrida queda a la vista de cualquiera.

Lo que esto no hace

  • No te protege en el momento. Si un día servimos otra cosa, esto no lo frena: lo deja registrado y cualquiera lo puede señalar. Es disuasión con rastro público, no un candado.
  • No mira el servidor. Lo que hace la API con lo que le llega no se puede verificar desde afuera. Por eso lo sensible se diseña para que no le llegue en claro, y la política dice dónde todavía le llega.
  • Puede fallar sin que nadie mienta. Con otra versión de Bun o de las dependencias, el build puede salir distinto. La guía de docs/verificar.md explica cómo distinguir una cosa de la otra.

Qué cambió

Cada versión anota lo que cambió en el registro de cambios. Lo que toca a tus datos va en su propia sección, "Datos y privacidad", para que no se pierda entre lo demás. Si algo de lo que corre no coincide con lo que dice, escribinos a hola@wefaber.net: es exactamente lo que queremos saber.
