# Localización

La interfaz está preparada para varios idiomas: español (listo), inglés y
portugués (en preparación). Hoy pasaron por el diccionario la isla, su menú y
Preferencias; el resto sigue con el texto en el componente y se migra por zonas.

## Usar una traducción

```tsx
import { useT } from '../../hooks/useLocale.ts'

const t = useT()
return <h2>{t('settings.title')}</h2>
```

Fuera de React: `translate(locale, key, params)` de `web/src/lib/i18n.ts`.

## Dónde vive cada cosa

| Pieza                         | Qué hace                                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `web/src/lib/locales/es.ts`   | Diccionario de origen. Toda clave nace acá; los demás se tipan contra este (`Messages`).                     |
| `web/src/lib/locales/en.ts`   | Inglés, `Partial<Messages>`: lo que falta cae al español.                                                    |
| `web/src/lib/locales/pt.ts`   | Portugués, igual.                                                                                            |
| `web/src/lib/i18n.ts`         | `LOCALES` (código, nombre, `lang`, `ready`), `translate`, `isSelectable`, `missingKeys`.                     |
| `web/src/hooks/useLocale.ts`  | `useLocale()` y `useT()`: leen `<html data-locale>`, sin pasar el idioma por props.                          |
| `web/src/lib/display.ts`      | El idioma elegido es `display.locale`: del dispositivo, como el tema. No viaja a la cuenta ni a la API.      |
| `web/src/hooks/useDisplay.ts` | Escribe `<html lang>` y `data-locale`. El script de `web/index.html` hace lo mismo antes del primer pintado. |

## Reglas

- Claves por zona: `island.*`, `menu.*`, `theme.*`, `settings.*`. Huecos con
  `{nombre}`: `t('x', { nombre: 'Ana' })`.
- Una clave nueva va primero a `es.ts` y en el mismo PR a `en.ts` y `pt.ts`. La
  prueba `web/src/lib/i18n.test.ts` falla si a un idioma le falta una clave.
- Las ofertas no se traducen: se muestran en el idioma en que se publicaron.
- Un idioma se marca `ready: true` en `LOCALES` cuando **toda** la interfaz está
  migrada, no cuando su diccionario cubre `es.ts`. Hasta entonces figura con
  "pronto" y no se puede elegir en producción. En `bun run dev` se pueden elegir
  todos para revisar lo traducido.
